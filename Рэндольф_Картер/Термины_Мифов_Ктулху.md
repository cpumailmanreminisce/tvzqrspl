# Термины Мифов Ктулху на ACF

Написания взяты из профилей и статей вики (ru). Источники: ЙС = Йог-Сотот, Гп = Гипнос, Нь = Ньярлатотеп, Нх = Ньярлатхотеп (дизамбиг), Аз = Азатот, Ту = Безымянный Туман, Тм = Тьма, Шн = Шуб-Ниггурат, Кт = Ктулху, Дг = Дагон, Шг = Шогготы, Хс = Хастур, Км = статья «Космология Мифов Ктулху», Обз = страница вселенной «Cthulhu Mythos».
Профили персонажей приоритетнее статьи «Космология»: если написания расходятся, первым идёт написание из профиля.

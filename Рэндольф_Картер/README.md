# Рэндольф Картер (Cthulhu Mythos)

Профиль персонажа для вики Anime Characters Fight (русский раздел).

- `Рэндольф_Картер.wiki` - готовая вики-разметка профиля. Скопируйте её целиком в редактор исходного кода страницы.
- `images/` - изображения для профиля. Загрузите их на вики под теми же именами (`Рэндольф_Картер_01.jpg` ... `Рэндольф_Картер_07.jpg`) до публикации страницы.
- `Термины_Мифов_Ктулху.md` - написания терминов Мифов Ктулху, собранные из существующих профилей вики.

Главное изображение `CarterR.jpg` уже есть на вики.
